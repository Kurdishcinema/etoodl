# EtooDL | حمّلها ⬇️

موقع تنزيل فيديوهات من جميع المواقع — مجاني، بدون تسجيل، واجهة عربية كاملة.

**الموقع الحي:** https://etooo77555eto.github.io/etoodl/

## شنو يسوي؟
- الصق رابط أي فيديو → تنزيل مباشر بجودات متعددة (حتى 4K) أو صوت MP3 فقط
- **تيك توك بدون علامة مائية** + نسخة HD + صور المنشورات
- **يوتيوب** بجودات كاملة مع الصوت، وخيارات صوت فقط
- يدعم انستغرام، فيسبوك، X، فيميو، ديلي موشن، تويتش، ساوند كلاود، ريديت، بينترست، سناب شات وأكثر من 1000 موقع

## شلون يشتغل؟
موقع ثابت (ملف واحد `index.html`) يشتغل بالكامل من متصفح الزائر:
- تيك توك ← TikWM API
- يوتيوب ← Piped API (مع احتياطي Cobalt)
- بقية المواقع ← خوادم Cobalt العامة (قائمة تنقّل تلقائي بين الخوادم)

لا يُخزَّن أي فيديو أو رابط على أي خادم خاص بالموقع.

## الاستخدام
افتح `index.html` أو زر الموقع الحي. للاستخدام الشخصي فقط — احترم حقوق النشر.
